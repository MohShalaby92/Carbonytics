# Carbonytics web app

The React 19 + Vite single-page app for Carbonytics. Setup, screenshots, and the full development guide are in the [repository README](../README.md).

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the Vite dev server on <http://localhost:3000> and forwards `/api` to the API on port 5000. |
| `npm run build` | Builds the production bundle into `build/`. |
| `npm run preview` | Serves the production bundle locally. |
| `npm run typecheck` | Runs the TypeScript compiler without emitting files. |

Design tokens, type, and component rules are in [`DESIGN.md`](DESIGN.md).
